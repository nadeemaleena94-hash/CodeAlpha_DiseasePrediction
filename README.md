# CodeAlpha Task 4: Disease Prediction from Medical Data

Predicts breast cancer (UCI Breast Cancer Wisconsin dataset, bundled with scikit-learn) using Logistic Regression, SVM, Random Forest and XGBoost, with cross-validation and hyper-parameter tuning.

## Setup
```
pip install -r requirements.txt
```

## Run
```
python disease_prediction.py
```

No download needed. Charts are saved as .png files.
